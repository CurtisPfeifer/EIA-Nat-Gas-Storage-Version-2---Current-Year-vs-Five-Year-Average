# EIA-Nat-Gas-Storage-Version-2---Current-Year-vs-Five-Year-Average
Python Script that pulls weekly U.S natural gas inventory from EIA and plots current levels against a 5-year average. Also show's 5-year average weekly injection/withdrawal rate against current. Now have Cooling Degree Days (CDD) and Heating Degree Days (HDD) to show impact against inventory. Also Created a prediction interval
